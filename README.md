# KaiMRE

KaiMRE runs MRE / VXP games on KaiOS.

Created by **dalbaeeeb228**.
Telegram: https://t.me/JavaBloxJ2ME

---

## English

### How to run a game

1. Put your game file in the app package and name it `game.vxp`.
   The file must be at the root of `application.zip`, next to `index.html`.
2. Repack `application.zip`, then pack it together with `metadata.json` into one zip.
3. Install the zip on your KaiOS device and open KaiMRE.

The game starts automatically. If `game.vxp` is missing, the app shows an error.

### Controls

| Key | Action |
|---|---|
| Arrows | Move |
| OK / Enter | Select |
| Soft keys | Left / right soft keys |
| Call | Call key (mapped to soft left) |
| End | End key |
| 0-9, *, # | Number keys |

### Sound

Game music plays through the speaker. Press any key once before the music starts,
because some devices block sound until the first key press.

### Exit

When the game exits, KaiMRE closes itself.

### Requirements

- KaiOS 2.5 or newer.
- Only use games you have the right to run.

## Русский

### Как запустить игру

1. Положите файл игры в пакет приложения и назовите его `game.vxp`.
   Файл должен лежать в корне `application.zip`, рядом с `index.html`.
2. Перепакуйте `application.zip`, затем упакуйте его вместе с `metadata.json` в один zip.
3. Установите zip на устройство KaiOS и откройте KaiMRE.

Игра запускается сама. Если `game.vxp` нет, приложение покажет ошибку.

### Управление

| Клавиша | Действие |
|---|---|
| Стрелки | Движение |
| OK / Enter | Выбор |
| Софт-клавиши | Левая / правая софт-клавиша |
| Call | Клавиша вызова (соответствует левой софт-клавише) |
| End | Клавиша завершения |
| 0-9, *, # | Цифровые клавиши |

### Звук

Музыка игры играет через динамик. Нажмите любую клавишу перед началом музыки,
потому что на некоторых устройствах звук блокируется до первого нажатия.

### Выход

Когда игра завершается, KaiMRE закрывается сам.

### Требования

- KaiOS 2.5 или новее.
- Используйте только игры, на запуск которых у вас есть права.
